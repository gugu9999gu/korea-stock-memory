# korea-stock-memory

한국주식 투자·거래 의사결정의 외부 장기기억 저장소입니다.

## 목적
- 예약작업과 수동 분석은 거래 판단 전에 이 저장소의 최신 기록을 우선 참조합니다.
- 신규 판단, 무효화, 손절, 청산, 사후평가를 사실 기반으로 누적합니다.
- 과거 성공/실패 이유를 다음 의사결정에 반영합니다.

## 기본 원칙
1. **사실과 판단을 분리**합니다. 시세·체결·보유수량은 브로커/공식 데이터로 확인된 값만 기록합니다.
2. **체결되지 않은 주문은 거래로 기록하지 않습니다.** 제안(PROPOSAL), 미리보기(PREVIEW), 주문제출(SUBMITTED), 체결(FILLED)을 구분합니다.
3. 수익률을 보장하거나 결과를 사후적으로 미화하지 않습니다.
4. 계좌번호, API 키, 인증정보 등 비밀정보는 기록하지 않습니다.
5. 각 거래는 단타(DAY), 스윙(SWING), 장기(LONG) 중 하나로 분류합니다.
6. 손절/무효화 조건과 최대 비중을 진입 전 기록합니다.

## 읽기 순서
1. `memory/strategy.md`
2. `memory/lessons.md`
3. `state/current.md`
4. 최근 `journal/YYYY-MM.md`

## 기록 위치
- 전략/운용 규칙: `memory/strategy.md`
- 누적 교훈: `memory/lessons.md`
- 현재 운용 상태: `state/current.md`
- 거래·판단 로그: `journal/YYYY-MM.md`
- 자동화용 준수 규칙: `AUTOMATION_RULES.md`

이 저장소는 거래 판단의 기억·감사 로그 역할을 하며, 브로커의 실제 체결내역을 대체하지 않습니다.
