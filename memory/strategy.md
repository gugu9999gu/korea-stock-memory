# Strategy Memory

## 기본 자금 배분
- DAY(단타): 최대 15%
- SWING(스윙): 최대 35%
- LONG(장기): 최대 50%

시장 레짐과 리스크에 따라 미사용 현금을 유지할 수 있으며, 위 비중은 목표가 아니라 **상한**입니다.

## DAY — 기관형 실행/리스크 관리
참고 원칙: VWAP, 거래대금, 상대강도, 갭 유지, 유동성, 명확한 촉매, 사전 손절.
- 급등 추격 금지
- 물타기/복수매매 금지
- 손절·청산 판단을 신규 진입보다 우선
- 기대손익비가 불리하면 거래하지 않음
- 같은 종목의 반복 점검은 장 마감 전 제한적으로 수행

## SWING — 추세/모멘텀
참고 원칙: AQR식 모멘텀·추세, Minervini류 추세 정렬.
- 20/50/200일 추세, 상대강도, 거래대금, 실적·공시 촉매 확인
- 최근 상승률만으로 진입하지 않음
- 진입 전 무효화 가격/조건과 보유기간 가설 기록

## LONG — 품질/가치
참고 원칙: Berkshire/Graham류 품질·가치 투자.
- 지속 가능한 경쟁우위
- 이익·현금흐름의 질
- 재무건전성
- 자본배분
- 밸류에이션과 안전마진
- 단기 주가 상승만으로 매수하지 않음

## 공통 리스크 규칙
- 확인되지 않은 뉴스/루머를 사실로 기록하지 않음
- 단일 종목 과집중 회피
- 거래 전 진입조건·무효화조건·손절·목표·최대비중 기록
- 실제 체결은 브로커/공식 데이터로 확인된 경우에만 FILLED로 기록
- 전략 성과는 승률뿐 아니라 기대값, 손익비, 최대낙폭, 규칙 준수율로 평가
